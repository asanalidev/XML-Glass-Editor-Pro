# XML Glass Editor Pro 💎
**XML Glass Editor Pro** — это современный, высокопроизводительный и визуально потрясающий редактор XML-документов с интерфейсом в стиле Blue Glassmorphism. Проект создан с использованием чистых веб-технологий (HTML5, Tailwind CSS, JavaScript) и оформлен в виде монолитного приложения. 
## 🚀 Основные возможности
* **Эстетика Blue Glassmorphism**: Полупрозрачные панели с размытием (`backdrop-filter: blur`), неоновые акценты, глубокие космические градиенты и приятная для глаз цветовая палитра.<br>
* **Интерактивный редактор**: Поддержка автоматических отступов при нажатии Enter, обработка клавиши Tab, подсчет строк и синхронизация скролла.<br>
* **Дерево документа (DOM Tree)**: Автоматический парсинг загруженного XML и построение иерархического дерева тегов и атрибутов в реальном времени.<br>
* **Валидация и консоль дебага**: Мгновенная проверка синтаксиса с детальным выводом ошибок парсинга (или подтверждением корректности документа).<br>
* **Поддержка множества форматов**: Открытие и сохранение файлов с расширениями `.xml`, `.vbox`, `.csproj`, `.xsl`, `.xhtml`, `.html`.<br>
* **Drag & Drop**: Возможность перетаскивать файлы прямо в рабочую область редактора.<br>
* **Быстрые шаблоны**: Предустановленные заготовки для каталогов (`catalog`), RSS-лент (`rss`) и конфигурационных файлов (`config`).<br>
* **Автоформатирование**: Приведение структуры документа к красивому стандартизированному виду в один клик.<br>

## 🛠 Технологии
* HTML5 (Семантическая разметка)<br>
* Tailwind CSS (Современные utility-first стили)<br>
* Vanilla JavaScript (ES6+) (Интерпретатор, DOM-парсер, обработчики событий)<br>
*FontAwesome (Иконки интерфейса)<br>
* Google Fonts (Шрифты `Inter` и `Fira Code`)<br>

## 📦 Установка и запуск
Поскольку проект реализован в виде монолитного файла (`index.html` + `favicon.ico`), для его работы не требуется установка Node.js, сборщиков или зависимостей.<br>
1. Скачайте или скопируйте repository.<br>
2. Дважды кликните по нему, чтобы открыть в любом современном веб-браузере (Chrome, Firefox, Edge, Safari).<br>

## 💡 Использование
1. **Загрузка файла**: Нажмите кнопку «**Открыть файл**» на панели управления или просто перетащите XML-файл в область редактора.<br>
2. **Редактирование**: Вносите изменения в коде. При нажатии `Enter` редактор автоматически сохраняет правильный отступ вложенности.<br>
3. **Проверка**: Нажмите «**Проверить**», чтобы убедиться в корректности тегов. В нижней консоли отобразится статус, а в левом сайдбаре построится интерактивное дерево.<br>
4. **Форматирование**: Нажмите «**Формат**», чтобы выровнять документ.<br>
5. **Сохранение**: Нажмите «**Сохранить**», чтобы скачать готовый файл на компьютер.<br>
